# TruePrice
An All-in-one platform where you can understand the true price of your purchase. 

- Understand the available offers easily.
- Get the best applicable offer on your purchase.

| TruePrice: Know the actual value of your product ; )

## Status

Under development — working on features and improvements.

## How to run

- Make sure you have Node.js installed.
- In the project folder, install dependencies:

	`npm install`

- Start the development server:

	`npm run dev`

- Open your browser at `http://localhost:3000`
